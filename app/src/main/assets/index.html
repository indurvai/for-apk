Native Android APK & Real NotificationListenerService Bridge

                
Browsers block websites and local .html files from reading other apps' notifications. Use the Native APK or import a phone dump below.

              

              
            


            
    
              
  1. Install the Native APK: Download NotifyTrace_Android_APK_Project.zip from the chat card and build the APK (1-click via GitHub Actions or Android Studio).
    2. 
              
  2. Enable Notification Access: On your Android phone, open Settings → Notifications → Notification access (Device & app notifications) and toggle NotifyTrace ON.
    3. 
              
  3. Automatic 365-Day Real History: The APK's background NotificationListenerService intercepts every notification from WhatsApp, Gmail, System, Messenger, and all other installed apps—including their real app icons—and logs them here for 365 days.
    4.
